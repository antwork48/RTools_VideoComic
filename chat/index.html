Chat Maker

The box is sized from the text itself, so margins stay exact for every message. Pick a theme color (swatches or any color), then a design preset. Batch: put one chat per line in the Batch list, optionally as "Label | message", and export every line as a PNG in one zip. Exports are transparent; MP4 fills the background with the chosen screen color for keying. GIF supports only 256 colors and on/off transparency.
