Comic Bubble Maker

Exports are always transparent. Use a type preset, then edit the text (new lines are kept). Halftone modes shade the inside of the bubble or add a dotted shadow. With Canvas set to Auto fit, the image is cropped tight around the bubble; pick a fixed size to place it with Position X and Y. MP4 has no transparency, so it fills the background with the chosen screen color for keying in Premiere. GIF supports only 256 colors and on/off transparency.
