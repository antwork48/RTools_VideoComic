Battle UI Maker

Pick a mode: command menu, dialogue box, or both. Put one command per line (and one help line per command in the same order). With Auto cycle on, the highlight steps through the commands, so set Duration to about commands x hold time for a clean loop. Layout is designed at 1920x1080 and scales to other sizes. Exports are transparent; MP4 fills the background with the chosen screen color for keying. GIF supports only 256 colors and on/off transparency. This is an original, inspired-by style and uses no game assets.
