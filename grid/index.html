Grid Maker

Pick a grid type and a preset, then tune the colors. Scroll X and Y are counted in whole cycles per loop (one cycle = one major block), so the animation always loops seamlessly; set Loop duration to control the speed. Floor is the retro perspective grid: Scroll Y moves it toward the camera, Scroll X slides it sideways. For a transparent background choose Background: transparent, then export PNG sequence or WebM. MP4 has no transparency and fills it with the chosen screen color. GIF supports only 256 colors.
